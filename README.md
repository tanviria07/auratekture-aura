Aura: voice concierge for Auratekture (https://auratekture.base44.app). A LiveKit Agents worker with Gemini through LiveKit Inference and a Synthesia interactive avatar. It controls the Auratekture Studio through LiveKit data messages (topic 'ui') and reads page context (topic 'context'). It can never sign or pay. Setup: copy .env.example to .env, fill in the keys, pip install -r requirements.txt, then python agent.py dev.
